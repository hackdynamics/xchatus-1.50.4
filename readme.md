# XCHATUS

XCHATUS is an IRC client for Windows and UNIX-like operating systems.  
See [IRCHelp.org](http://irchelp.org) for information about IRC in general.  
For more information on XCHATUS please read our [documentation](https://xchatus.readthedocs.org/en/latest/index.html):
- [Downloads](http://xchatus.github.io/downloads.html)
- [FAQ](https://xchatus.readthedocs.org/en/latest/faq.html)
- [Changelog](https://xchatus.readthedocs.org/en/latest/changelog.html)
- [Python API](https://xchatus.readthedocs.org/en/latest/script_python.html)
- [Perl API](https://xchatus.readthedocs.org/en/latest/script_perl.html)

# apt install meson libcanberra-dev libdbus-glib-1-dev libglib2.0-dev libgtk2.0-dev libluajit-5.1-dev libpci-dev libperl-dev libssl-dev python3-dev python3-cffi mono-devel desktop-file-utils<br>
# meson build<br>
# ninja -C build<br>
# ninja -C build install<br>
